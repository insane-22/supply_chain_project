# Supply Chain Project
## Project Overview
This project focuses on analyzing and optimizing the unorganized food supply chain using data-driven techniques. The goal is to identify inefficiencies in procurement, pricing, and vendor operations, and provide actionable insights that improve decision-making.

The system leverages data analysis and optimization strategies to support vendors in reducing costs and improving supply chain efficiency.

## Objectives
- Analyze vendor purchasing and pricing patterns
- Identify inefficiencies in the supply chain
- Optimize supplier selection based on cost and demand
- Provide data-driven insights for better decision-making

## Methodology
The project is divided into the following stages:

### 1. Data Collection & Loading: 
- Importing datasets related to vendors, pricing, and demand
- Structuring raw data for further processing
### 2. Data Cleaning & Preprocessing: 
- Handling missing or inconsistent values
- Formatting and normalizing data
- Preparing clean datasets for analysis
### 3. Exploratory Data Analysis (EDA):
- Understanding pricing trends
- Identifying demand patterns
- Analyzing vendor behavior
### 4. Optimization Logic:
- Evaluating supplier options
- Selecting cost-efficient procurement strategies
- Applying rule-based or analytical methods for decision-making
### 5. Visualization & Insights:
- Generating graphs and summaries
- Highlighting key findings
- Presenting actionable insights

## Key Outcomes
- Identification of cost-saving opportunities
- Improved understanding of vendor demand patterns
- Data-driven supplier selection strategy
- Enhanced decision-making framework for procurement

## Challenges Faced
- Inconsistent and Missing Data:
The dataset contained missing values, inconsistent formats, and noisy entries, requiring careful preprocessing to ensure reliability.
- Lack of Structured Supply Chain Data:
Real-world unorganized sector data is often unstructured, making it difficult to directly apply standard analytical techniques.
- Designing Optimization Logic:
Developing a meaningful supplier selection strategy without advanced machine learning models required careful rule-based decision design.
- Interpreting Real-World Patterns:
Identifying meaningful trends from limited or imperfect data required multiple iterations of analysis and validation.
- Balancing Simplicity and Effectiveness:
Ensuring the solution remained simple enough to implement while still providing impactful insights was a key challenge.

## Future Scope
